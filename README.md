## 🔧 Configuration Guide

### Setting Up Face Tracking

Open VTube Studio and go to Settings > Tracking. Import the tracking preset file from the toolkit folder. This sets the optimal values for:

- Eye tracking sensitivity
- Mouth shape detection
- Head rotation limits
- Blink detection speed

### Configuring Expressions

The expression presets are stored in a text file. Open it and copy the lines into VTube Studio's expression editor. You can then assign each expression to a key on your keyboard.

### Setting Up OBS

Open OBS and go to Scene Collection > Import. Select the scene template file included in the toolkit. This creates a complete scene with:

- Your avatar positioned in the corner
- A webcam overlay area
- Placement for alerts and chat overlays

### Mapping Hotkeys

The hotkey configuration tells VTube Studio which keyboard keys trigger what actions. The default setup uses:

- A through H for different expressions
- 1-6 for quick toggles
- Space to re-center your avatar
- Tab to show/hide the tracking window

## 🎯 Troubleshooting Common Issues

### My Avatar Is Not Moving Smoothly

Check your webcam placement. Make sure your face is well-lit and the camera is at eye level. You can also lower the tracking sensitivity in VTube Studio for smoother movement.

### OBS Scenes Are Not Importing

Make sure you have the latest version of OBS Studio installed. Some older versions don't support the scene format used in this toolkit.

### Hotkeys Aren't Working

Verify that VTube Studio has focus as the active window. Some hotkeys only work when VTube Studio is in the foreground. You can change this in the settings.

### Face Tracking Is Laggy

Close unnecessary background programs. Also, try reducing the webcam resolution in VTube Studio settings to improve performance.
